# Telecom Customer Churn — Python Analysis

This folder contains the notebook, source dataset, and report for an exploratory analysis of telecom customer churn.

## Files

- [TCA.ipynb](./TCA.ipynb) — Jupyter notebook.
- [Customer Churn.csv](./Customer%20Churn.csv) — dataset used by the notebook.
- [Telco Customer Churn Analysis.pdf](./Telco%20Customer%20Churn%20Analysis.pdf) — accompanying report.

## Dataset

The notebook's displayed dataset has **7,043 rows and 21 columns**. It contains customer attributes, subscribed services, contract details, payment information, and churn status.

## Tools

Python, pandas, numpy, matplotlib, and seaborn.

## Run the notebook

1. Open `TCA.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
2. Place `Customer Churn.csv` in the notebook's working directory.
3. Run the cells in order.

This repository documents exploratory analysis. Predictive-model performance claims should only be added when the model, evaluation method, and baseline are included in the notebook.
